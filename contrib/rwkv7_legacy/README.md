# Legacy RWKV7 Experiments

This directory preserves the pre-`0.1` RWKV7 kernels, wrappers, benchmarks,
and overlap example for source history only. They are not part of the
`rosa_soft` package, build, API, tests, or release artifacts.

The code is not maintained against the current operator ABI. Treat it as an
external integration starting point, not as a supported ROSA execution path.
